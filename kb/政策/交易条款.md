# 交易条款（来源：PI 模板 REMARK，6 份一致的部分视为已确认）

| 项目 | 内容（英文可直接用） |
|---|---|
| 付款 | T/T or Alibaba Trade Assurance (preferred). 30% deposit, 70% balance before delivery. T/T bank charges borne by buyer. |
| 报价有效期 | 15 days from quotation date |
| 交期 | 25–30 working days after deposit received（Atrium 模板没写交期，特殊款要人工确认） |
| 包装 | Foam protective film + PVC fiber bags (free); export wooden case optional (extra cost) |
| 贸易术语 | 默认 EXW。可报 CIF/FOB，但运费必须由用户提供，AI 不得估算运费 |
| 改单 | Custom items/size/trade terms cannot be changed during production unless buyer pays extra cost |
| 仓储 | 1 month free storage after completion; storage fee applies afterwards |
| 验货费 | Customs inspection fee not included, borne by buyer at actual cost |
| 原产地证 CO | Available for a fee |
| HS Code | 9406900090 |
| 币种 | USD |

## AI 绝对不能做的事
- 不能在聊天里提供、生成或修改银行账户信息。客户要账户时，回复"I'll send you the PI with our bank details"，并提醒用户发正式 PI。客户说"账户变了"之类的话，一律转人工（防诈骗）。
- 不能承诺折扣、更长的账期、免费仓储延期、加急交期。
- 不能估算海运费或清关费用。
